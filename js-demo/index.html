🔗 API Endpoints

Your Supabase project exposes these PostgREST endpoints:

Kingdoms

GET /rest/v1/kingdom_lorenz_steffen

POST /rest/v1/kingdom_lorenz_steffen

GET /rest/v1/kingdom_lorenz_steffen?id=eq.1

PATCH /rest/v1/kingdom_lorenz_steffen?id=eq.1

DELETE /rest/v1/kingdom_lorenz_steffen?id=eq.1

Furstentumer

GET /rest/v1/fuerstentuemer

POST /rest/v1/fuerstentuemer

GET /rest/v1/fuerstentuemer?parent_id=eq.1

PATCH /rest/v1/fuerstentuemer?id=eq.1

DELETE /rest/v1/fuerstentuemer?id=eq.1

Joins

GET /rest/v1/fuerstentuemer?select=*,kingdom_lorenz_steffen(*)

This joins furstentumer with their parent kingdom

Note: You need to enable RLS and create policies for public access.
